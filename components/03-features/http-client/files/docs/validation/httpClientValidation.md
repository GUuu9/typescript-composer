# httpClient 파트 단위 검증

전체 구성 조합을 검사하지 않고 이 기능의 독립 동작만 확인합니다. 결과를 받기 전에는 미검증입니다. 에이전트는 이 검사를 실행하지 않았습니다.

## 준비

기존 project 앱 대신 별도 임시 경로의 새 기본 앱을 사용합니다. 기능 docs에 따라 필요한 소스·공통 의존 파일·패키지를 복사하고 test/frontend/api.test.ts도 같은 상대 위치로 복사합니다. 테스트는 실제 앱 DI와 분리된 대역·독립 객체를 사용하므로 업무 Usecase 연결이나 운영 .env가 필요하지 않습니다. Node 버전은 앱 .nvmrc를 따릅니다. 의존성이 이미 준비되어 있으면 설치를 반복하지 않습니다.

## 실행

```sh
# 실행 위치: 새 임시 앱 루트 터미널
# 적용: 이 기능의 단위 검사만 실행합니다. 전체 npm test·verify·build를 반복하지 않습니다.
node --test test/frontend/api.test.ts
```

확인 범위: fetch 대역으로 경로·JSON 응답·오류·취소를 확인합니다. 외부 API는 호출하지 않습니다. 실패하면 해당 테스트와 직접 의존하는 코드만 수정하고 그 검사만 다시 실행합니다. 단위 검사 통과를 실제 앱 연결·외부 통신·배포 검증으로 설명하지 않습니다.

## 제외 범위

전체 조합 생성·패키지 재설치·전체 check/test/build·외부 연결·loopback 통신·긴 제한시간·파일 회전·실기기/GUI는 기본 검증에 포함하지 않습니다. 해당 부분에서 실제 문제가 보고되거나 명시적 요청이 있을 때만 관련 최소 재현 검사를 별도로 수행합니다. 기존 테스트 파일에 다른 검사가 남아 있어도 이 문서의 실행 범위에는 포함하지 않습니다.
