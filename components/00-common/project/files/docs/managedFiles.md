# 생성 후 관리 파일의 수정 기준

기능을 추가할 때 DI·업무 소스·README·기능 문서는 직접 수정합니다. 아래 관리 기록과 자동 산출물은 기능 연결을 위해 손으로 편집하지 않습니다. 실패한 검사를 통과시키려고 기록을 바꾸지 말고 실제 코드·설정·명령의 원인을 확인합니다.

## 직접 수정하지 않는 파일

```jsonc
// 파일: .composer/state.json
// 임의 수정 금지: 최초 구성·원본 버전·파일 기준값·관리 패키지/명령·활성 상태 기록입니다.
// 기능 추가를 위해 hash·baseline·components·pendingComponents·managedEntries를 변경하지 않습니다.
// 생성기와 npm run verify가 관리합니다. 검사 실패를 이 파일 수정으로 우회하지 않습니다.
// 이 블록은 주석 안내이며 실제 JSON 파일에 붙여 넣지 않습니다.
```

```jsonc
// 파일: .composer/diagnostic.json (실행 결과로 생성된 경우)
// 임의 수정 금지: verify의 실패 단계·취소·성공 진단 기록입니다.
// 실제 문제를 수정하고 필요한 명령을 다시 실행해 진단을 갱신합니다.
// 이 블록은 실제 JSON 파일에 붙여 넣지 않습니다.
```

```jsonc
// 파일: package-lock.json
// 수동 편집 금지: 실제 package.json 변경 후 npm으로 갱신합니다.
// 의존성을 추가하거나 제거했다면 npm install 등 해당 npm 명령으로 생성한 결과를 저장합니다.
// 이 블록은 실제 JSON 파일에 붙여 넣지 않습니다.
```

```text
# 위치: dist/·release/·node_modules/ (해당 구성에서 생성된 경우)
# 임의 수정 금지: 빌드·패키징·설치 산출물입니다.
# 수정할 소스는 src/이며 산출물을 수정해 기능을 추가하지 않습니다.
# .git/ 내부도 직접 편집하지 않고 필요한 Git 명령으로 관리합니다.
```

## 기존 관리 항목을 유지하는 파일

```jsonc
// 파일: package.json
// 추가 기능의 dependencies·devDependencies·새 scripts 항목은 병합할 수 있습니다.
// 기존 생성 패키지의 버전과 관리 scripts를 기능 추가 목적으로 임의 변경·삭제하지 않습니다.
// verify는 기존 관리 항목을 검사합니다. 의도적인 도구 업그레이드는 별도 변경으로 검토합니다.
// 실제 JSON에는 주석을 넣지 않습니다.
```

```js
// 파일: scripts/verify.mjs
// 추가 기능 연결을 위해 수정하지 않습니다.
// 상태 검증·실패 보존·구성 활성화 검사를 제거해 오류를 우회하지 않습니다.
// 검증 도구 자체의 결함 수정은 별도 유지보수 작업으로 수행합니다.
```

## 직접 수정하는 파일과 구분

- backend/core/di.ts·frontend/core/di/di.ts: 초기 연결 이후 사용자 소유입니다. 추가 객체 생성·주입·수명 등록을 작성합니다.
- src/의 업무 코드·Bridge·Usecase·Service·Api·shared 계약·preload: 실제 기능에 맞게 수정합니다. IPC는 관련 경로·메서드·발신자 검증을 함께 유지합니다.
- src/shared/ipcRoutes.manifest.ts: Electron의 초기 경로 목록입니다. 새 업무 경로를 연결할 때 Main·preload·Api와 일치하도록 수정할 수 있습니다. 이 파일 이름을 이유로 사용자 수정 금지로 취급하지 않습니다.
- .env.example: 필요한 공개 설정 설명과 키를 추가합니다. 실제 .env는 사용자만 작성하며 비밀값을 버전 관리에 넣지 않습니다.
- README.md·docs/: 기능 사용법·패키지 버전·적용 이력에 맞게 수정합니다.

주석을 지원하는 관리 스크립트에는 파일 상단에도 같은 경고를 표시합니다. JSON·lock·자동 산출물에는 문법을 깨는 주석이나 도구가 정의하지 않은 경고 필드를 추가하지 않습니다.

이 문서는 수정 범위를 안내하며 운영체제 파일 권한이나 새로운 자동 보호 검사를 추가하지 않습니다. 기존 앱의 파일을 자동 변경하지 않습니다.
