# VS Code workspace 생성 계약

상태: 사용자 승인 계약입니다. 구현 후 실제 실행 검증은 별도로 기록합니다.

## 실행과 결과

제안 명령은 Composer 루트의 npm run workspace입니다. 인자 없이 대화형 터미널에서 실행합니다. project/의 바로 아래 실제 디렉터리를 이름순으로 표시하고 번호를 쉼표로 복수 선택합니다. 숨김 폴더·심볼릭 링크·일반 파일은 제외하며 중복·범위 밖·잘못된 입력을 거부합니다. 선택을 취소하면 파일을 쓰지 않습니다.

Composer 루트를 항상 포함하고 선택 폴더의 상대 경로를 folders에 추가해 typescript-composer.local.code-workspace를 생성합니다. git.autoRepositoryDetection은 true로 설정해 workspace 폴더의 저장소를 탐색하도록 합니다. Git 유무를 확인하기 위해 앱 내부를 읽거나 Git 명령을 실행하지 않습니다. VS Code 실행·확장 설치·앱 수정·git init·commit·remote·push는 수행하지 않습니다.

## 보호

앱 이름은 탐색 결과에서만 선택하며 임의 경로를 받지 않습니다. project 자체가 심볼릭 링크이면 거부합니다. 선택 폴더는 쓰기 직전 다시 일반 디렉터리인지 확인합니다. 결과는 Composer 루트에만 기록하고 기존 .gitignore의 해당 파일 제외 규칙을 유지합니다.

기존 workspace가 일반 파일이면 교체 여부를 묻고 명시적 동의 후 교체합니다. 심볼릭 링크·디렉터리 등은 거부합니다. 실패 시 기존 파일을 손상하지 않도록 임시 파일에 완성한 후 교체하며 새 파일 생성은 기존 파일을 덮어쓰지 않게 처리합니다. 사용자의 다른 workspace 파일을 찾거나 삭제하지 않습니다.

## 검사

임시 디렉터리만 사용하는 단위 테스트를 작성합니다. 번호 선택·경로 목록·중복과 잘못된 입력·기존 파일 보호를 확인합니다. 기존 project 앱은 테스트 대상으로 사용하지 않습니다. 에이전트는 구문·diff만 확인하고 단위 검사는 사용자가 명시적으로 요청한 경우에만 실행합니다.
