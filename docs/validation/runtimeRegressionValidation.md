# 수명·오류 처리의 파트별 회귀 확인

기본 검증은 변경한 기능의 docs/validation 단위 검사 한 개로 제한합니다. 전체 조합 생성·통신 연결·빌드는 실행하지 않습니다. 현재 파일은 실제 문제가 보고되었을 때 관련 파트를 고르는 안내입니다.

- HTTP 오류 전달 문제: HttpCommunication의 서버 error와 failure 전달을 대역으로 확인합니다.
- TCP 늦은 오류 문제: TCP 단위 검사로 프레임·설정을 먼저 확인하고 실제 단절 재현이 필요한 경우에만 해당 이름의 loopback 검사를 선택합니다.
- TCP 수 제한 문제: 대기 업무와 새 요청만을 대상으로 하며 여러 통신을 함께 띄우지 않습니다.
- 빌드 정리 문제: 새 임시 디렉터리에 backend/shared·frontend·preload 파일을 놓고 정리 스크립트의 삭제 범위만 확인합니다. 전체 빌드를 반복하지 않습니다.

명령과 재현 대역은 문제 요청 범위에 맞춰 준비합니다. 현재 문서가 해당 회귀 검사를 실행하거나 통과했다는 뜻은 아닙니다. 기존 project 앱·운영 데이터·외부 서버는 사용하지 않습니다.
